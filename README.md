# np-arslan-vlahovljak

## DOMACI ZADATAK BROJ 1

### ZADATAK 1

**Upit:**

Kontekst: Python 3.13. Radimo na malom web shopu za prodaju sportske opreme. Cijene proizvoda čuvamo u listi (npr. [49.99, 15.50, 120.00]), a prosječnu cijenu koristimo na stranici s izvještajem za svaku kategoriju proizvoda.

Zadatak: napiši Python funkciju calculate_average_price(prices) koja vraća prosječnu cijenu zaokruženu na 2 decimale.

Ograničenja: samo standardna biblioteka, type hints, obrada grešaka (prazna lista, neispravni podaci).

Format odgovora: kod, pytest testovi i kratko obrazloženje rješenja

**Obrazloženje:**

Jedino što sam ja uočio kao nedostatak jeste nedostatak same liste cijena koju sam dodao sam i ispisivanje rezultata u konzoli da bih odmah provjerio da li radi. To je navika od programiranja na koje sam navikao, jer pytestove nisam ranije koristio za pet projekte.
